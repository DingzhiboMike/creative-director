# creative-director

Скилл для Claude.

AI-креативный директор: от брифа к инсайту, от инсайта к идеям через структурные методики (SIT, TRIZ, бисоциация, латеральное мышление), затем оценка по взвешенным критериям с калибровкой Cannes/D&AD/HumanKind и итеративная доработка до сильной идеи.

## Когда использовать

- Придумать концепцию кампании или Big Idea
- Найти инсайт под бриф
- Оценить и усилить существующую креативную идею

Не подходит для медиапланирования, бюджета продакшена, логотипов и айдентики, финального копирайтинга.

## Установка

**Claude Code.** Склонируйте репозиторий в папку скиллов:

```bash
git clone https://github.com/DingzhiboMike/creative-director.git ~/.claude/skills/creative-director
```

**Claude.ai / десктоп-приложение.** Скачайте репозиторий как ZIP (Code → Download ZIP) и загрузите его в настройках Claude, в разделе со скиллами.

После установки скилл включается сам, когда запрос подходит под его описание. Можно вызвать и явно — по имени `creative-director`.
